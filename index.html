ABOUT

关于这个页面

「掌机口袋」是一个纯前端的 GBA 模拟器外壳：内核是 mGBA 编译成的 WebAssembly，由 EmulatorJS 负责加载与输入，界面、游戏库和文件管理都是本地代码。整个站点没有后端，不上传、不请求任何外部地址。

内置游戏为什么只有几款？

因为《宝可梦》《黄金太阳》《火焰纹章》这类商业卡带的 ROM 是有版权的，不能打包分发——内置的每一款都是作者明确允许免费下载 / 开源的同人作品（µCity Advance、Blind Jump、Minicraft GBA），卡片上有各自的许可证与作者。

想玩自己收藏的那款？

只要你有卡带和一部能读卡带的设备，把 ROM 转储成 .gba 后从这里导入即可，它只存在你本机的浏览器里。不存在「下载 ROM」的入口，这是这个项目的底线。

数据都在哪

导入的 ROM 存在 IndexedDB；存档（.sav）、即时存档（.state）由 EmulatorJS 存在本地数据库。清除浏览器站点数据会一并删除，重要进度建议定期用菜单里的「导出存档」备份。

技术栈

原生 HTML / CSS / JavaScript，无框架、无构建。EmulatorJS 运行时已完整镜像到本地 data/，首次启动不需要联网。需要通过本地 HTTP 服务打开（WebAssembly 与 Worker 不允许 file://）。
